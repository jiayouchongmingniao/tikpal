# 场景环境音与 P2 体验交付（207，2026-09-12）

## 状态与范围

本记录是 `192.168.10.207` 的当前实现与验收边界。交付包括场景环境音与
Hi-Fi 的互斥交接、15 分钟场景环境声资产，以及 P2-1 至 P2-4 的前端体验
优化。它不改变 ALSA、MPD、Explore provider 或现有音源切换 API 的基础
契约；P2 部署只替换前端静态包，不重启服务。

场景视频继续使用现有无人、无文字的自然循环原片；视频层永久静音。每个
场景的独立环境声来自 `public/assets/scenes/audio/`，由
`scene_audio_sources.json` 保存 Pixabay 来源和许可、作者、源文件名及处理
方式。成品为 48 kHz 立体声、96 kbps VBR Opus、约 15 分钟，长渲染前在
尾首以 0.8 秒交叉淡化。`scene_videos.json` 同时保存音频文件、SHA-256 与
每场景音量标定；OTA 必须连同清单校验并原子安装视频和音频。

当前调校保留了低干扰取向：云海使用柔和风声而非鸟鸣，禅意小院为较低的
水流增益，深夜图书馆降至 `-8 dB`，禅意小院降至 `-6 dB`；雨窗采用 45 秒
雨声、15 秒安静的包络，避免持续密集雨声及不合适的素材事件。

## 场景音与 Hi-Fi 交接

### 原子场景选择

场景库卡片通过现有 `set_scene` / `set_mode` 请求，并明确写入
`sceneSoundEnabled: true`。选择卡片即选择画面并启用该卡片的环境声；不会
仅因切换 Focus、Calm、Sleep 模式而意外起播。

在开始场景声之前，服务端读取真实活动音源并先停止旧持有者，保证 DAC
同时只有一个实际音源：

- 本地曲库（`mpd`）或电台（`radio`）会写入私有、持久化的
  `.tikpal/room-scene-audio-handoff.json`，记录可恢复曲目/电台和进入场景前的
  播放或暂停状态。
- Spotify、AirPlay、蓝牙、DLNA 等外部输入会先停止，但绝不写入这个恢复快照，
  因此不会在离开场景时被自动重连。
- 已在场景声中改选另一张场景卡，只交换场景媒体，不覆盖最初的本地音乐快照。

进入 Hi-Fi 时先停止场景声，再只尝试恢复仍然有效的本地曲库曲目或电台，并
保留进入场景前的暂停状态。曲目删除、电台失效或恢复失败时保持静音并清除
快照，不猜测或回退至另一来源。用户明确选择任一非场景来源、停止场景会话、
或计时结束时同样清除快照；场景内的暂停/继续不清除它。

### 与全局 remembered source 的关系

场景交接快照和 `audio.rememberedSource` 是两个不同的状态：

| 状态 | 所属范围 | 写入内容 | 用途 |
| --- | --- | --- | --- |
| `room-scene-audio-handoff.json` | 单次“进入场景 → 明确回 Hi-Fi”交接 | 仅本地曲目/电台及原播放状态 | 仅在从场景回 Hi-Fi 时消费，成功或不可恢复时清除 |
| `audio-source-memory.json` / `audio.rememberedSource` | 全局播放来源记忆 | 本地曲库、电台及外部来源的通用记忆 | 启动、恢复和既有 Hi-Fi 来源策略 |

场景交接不会复用、覆盖或改写全局 remembered source。这样场景离开时只恢复
用户刚才的本地聆听上下文，而不会把外部来源重新拉起或污染其它恢复路径。

## P2 前端体验

### P2-1：设置与自检

- 音频预设首层按意图显示“日常聆听 / 纯净直出 / 睡前聆听 / 自定义设置”；
  技术特性、MPD、输出设备、采样率和 ReplayGain 收入“技术详情”。
- Explore 自检明确为“窗口与进程检查”；成功为“检查通过”，并说明它不验证
  网站、账号、地区限制或实际播放。
- Tikpal 自有 UI 文案覆盖英语、简体中文、德语、意大利语、韩语、日语和西语；
  品牌与第三方内容保持原样。

### P2-2：首次引导

首次用户先完成 Focus / Calm / Sleep / Hi-Fi 启动模式选择，不再被六项手势
说明遮挡。选择后进入非阻断两步提示：先轻点空白处显示控制，再指向当前
播放/暂停入口；若没有可控播放，则第二步提供打开 Player 的入口。该流程不
自动启动音乐或场景声，完成互动或跳过后才写入现有
`tikpal.onboardingDismissed.v1`。

已完成旧引导的用户不会再次看到首次提示。Settings 的“启动指南”仍可打开
完整参考对话框，保留 Tab 焦点循环、Escape 关闭和六项手势说明。

### P2-3：播放身份与直播

Player、屏保、Hi-Fi 封面兜底和 Console 共用播放展示解析器。解析顺序为：
可信的已播放元数据、活动队列元数据、可安全解析的本地文件名，最后才使用
本地化中性兜底。无意义的 `Unknown Artist`、`Untitled`、路径、URL 和文件
扩展名不会直接显示给用户。

电台或直播在没有可信总时长时显示“直播”及真实音源身份，隐藏进度条与
`--:--`；本地可定位曲目继续保留进度和 seek。

### P2-4：折叠 Explore 错误

Explore 折叠边条中的失败 `!` 是可聚焦、可点击的按钮。点击后显示贴边短提示：

- 面板布局失败：`重试展开` 或 `退出 Explore`。
- 退出失败：`重试退出` 或 `展开查看`。

关闭中的 `…` 仅表示进行中，不再与失败混用；请求期间相应动作禁用并保留
状态播报。实现复用现有 panel-mode 和 close 生命周期，不增加服务端接口。
