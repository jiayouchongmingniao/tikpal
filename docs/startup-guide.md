# Startup Guide：轻量手势提示

## 目的与交互

2026-09-09 将开机三步模拟练习改成一页六条提示，让用户快速了解操作，
不要求练习、翻页或等待“识别成功”。保留原有主题与系统字体继承。

| 提示 | 实际行为 |
| --- | --- |
| 轻点显示控制 | 在房间主界面显示控制；非 Hi-Fi 模式还可能打开音源选择。 |
| 左侧调节亮度 | 在左边缘上下滑动；实际范围由设备能力和后端限幅决定。 |
| 右侧调节音量 | 在右边缘上下滑动。 |
| 下滑进入播放页 | 从房间主界面进入 Player。 |
| 长按打开快捷菜单 | 从房间主界面进入 Quick Menu。 |
| 播放页或设置页上滑返回 | 从 Player 或 Settings 返回房间主界面。 |

右上角设置入口继续使用原行为，本次不改变手势识别代码。Player 与设置页
使用现有 `useOverlayReturnGesture`：向上位移超过 80 CSS px，并满足横向
偏移限制后返回。网页播放器使用自己的控件，提示不承诺其支持这些手势。

关闭按钮、完成按钮和 Escape 均关闭提示。Tab / Shift+Tab 在两个按钮之间
循环；打开时焦点进入提示，关闭时尝试恢复之前仍存在的焦点元素。
没有自动关闭计时，也没有任何模拟亮度、音量写入。

## 首次启动、重开与持久化

- 继续使用浏览器本地键 `tikpal.onboardingDismissed.v1`，不升级键版本，
  不清除已有“已看过”记录；新版本不会强制老用户重看。
- 可从设置重新打开。已有 Explore 关闭与返回房间界面的处理保持不变。
- 提示显示时暂停开机模式选择的显示和 8 秒自动关闭计时；关闭提示后
  模式选择才开始显示。视频 ready 条件仍属于模式选择原有逻辑。
- 删除旧教程的步数、背景压暗和场景音静音状态。轻量提示不修改亮度、
  音量、场景、音源或字体设置；正常遮罩仍用于区分前后层。
- 提示关闭本身不选择模式或音源，后续仍走原来的模式选择流程。

## 多语言与字体

六条提示、标题、按钮和页脚均通过现有 `useI18n().t` 读取文案。
六条提示覆盖英文、简体中文、德语、意大利语、韩语、日语、西班牙语。
本次补齐日语和西班牙语旧提示键，并为七种语言添加
`onboarding.returnTitle`。删除页脚“所有手势只在房间主界面生效”的
错误范围描述，保留网页播放器例外。

字体继承根元素 `--app-font-family`；根元素的 `data-font-theme` 由
系统偏好管理。提示没有独立字体选择，不另存语言或字体。
